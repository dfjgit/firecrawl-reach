# 采集情报报告规范（v0.1 · 迭代中）

> 目标：把各采集源抓到的最新信息，转成一份**"信息 → 分析 → 知识图谱回流"**的报告。
> 每份报告由 `tools/generate_report.py` 生成，本文件是格式与判断标准。
> **本规范随使用效果持续迭代**——每轮报告后对照"哪里解读不到位/图谱没对上"，更新本文件。

## 1. 报告结构（固定骨架）

```
# 情报采集报告 YYYY-MM-DD
## 0. 总览
   - 本轮有效源数 / 新增条目数 / 涉及板块数 / 知识图谱命中数
## 1. 各源信息与解读（按源分组）
   ### 1.1 <源名>（<源id>）
       ▸ 条目：[时间] 标题/内容摘要（原文链接）
         ▸ 解读：这条信息在讲什么，为什么值得注意
         ▸ 图谱关联：[命中] supply:氢氟酸 / event:xxx / policy:xxx（详见 §2 标记规则）
         ▸ 图谱动作：补充 / 更新 / 验证 / 无（不匹配时写"无，待积累"）
   ## 2. 知识图谱更新说明（机器可执行的变更清单）
       - [补充] supply_chain: 新增节点/边...
       - [更新] events: evt_xxx 状态/传导链...
       - [验证] policy:pol_xxx 传导链置信度提升...
   ## 3. 缺口与建议
       - 哪些信息没采到/图谱里没有，建议下一步
```

## 2. 图谱关联标记规则（核心）

判断"这条信息是否命中知识图谱"，按以下优先级：

| 优先级 | 匹配对象 | 命中示例 | 标注格式 |
|---|---|---|---|
| P0 | 精确实体（图谱节点名） | "氢氟酸" → supply:氢氟酸 | `[P0-实体] supply:氢氟酸` |
| P1 | 事件（events registry 关键词） | "伊朗" → evt_mig_019 美伊关系缓和 | `[P1-事件] evt_mig_019` |
| P2 | 政策（policy 关键词） | "新型电力系统" → pol_new_power_system_15th | `[P2-政策] pol_new_power_system_15th` |
| P3 | 板块（stock_profiles sector） | "半导体" → sector:半导体 | `[P3-板块] sector:半导体` |
| P4 | 无命中 | 内容与图谱无关 | `[P4-无命中]` |

**命中规则**：
- 条目的 content/title 含实体名或实体名子串（≥2 字符，排除"上涨/下跌"等过泛词）→ 命中
- 同一实体在 P0-P3 多级命中时取最高级（P0 优先）
- 命中后顺带取该实体的 1 跳邻居作为"图谱上下文"（展示实体在图中连着什么）

## 3. 解读要求

每条命中图谱的信息，解读必须包含：
1. **事实层**：这条信息直接说明了什么
2. **图谱层**：与图谱中已有内容一致/矛盾/补充（引用图谱节点数据）
3. **投资层**（仅对 P0-P3 命中）：对产业链/板块的潜在影响方向（正面/负面/中性）

未命中图谱的信息：只写事实层，图谱层写"知识图谱暂无对应节点，建议后续积累"。

## 4. 图谱补充/更新规则（机器可执行清单）

每轮报告生成时，对命中条目产生动作清单，**但生成器只建议、不写入**（人工确认后执行）：

| 动作 | 触发条件 | 建议写入 |
|---|---|---|
| 补充 | 信息含图谱没有的实体/关系 | supply_chain: 节点 `xx`（category: 推断） |
| 更新 | 图谱已有实体但信息是新的时间点 | events: evt_xxx timeline 追加 |
| 验证 | 信息印证图谱已有传导链 | policy: pol_xxx confidence +0.05（人工核） |
| 无 | 无命中或重复 | — |

## 5. 迭代机制

- 每轮报告底部固定附"规范反馈"：本轮哪些解读用户不满意 / 哪些标记规则误判 → 回填到本文件
- v0.1 起跑，目标：命中率（P0-P3 / 总条目）≥ 40%，解读被用户采纳率 ≥ 70%

## 6. 执行方式

```bash
cd Agent-Reach-main
python tools/generate_report.py          # 读 ~/.agent-reach/acquisition/data/*.jsonl
python tools/generate_report.py --since 6h   # 只看最近 6h
python tools/generate_report.py --out report.html  # 输出 HTML（默认 markdown）
```

## 7. 字段清洗与标题规则（v0.1.1，2026-08-04 迭代）

**问题**：①财联社电报 title 为空导致条目"无标题"；②虎嗅 content 含 `<figure><img>` 原始 HTML，进 markdown 被当成真实标签执行，长 URL 不换行撑坏布局（表现为"内容越来越窄"）。

**规则**：
1. **标题兜底**：title 为空 → 从正文提取首句（去电报时间戳 `11:09:47` 与"财联社X月X日电"前缀），按句子边界（。！？!?）截断 ≤60 字；仍空才标"(无标题)"
2. **HTML 清洗**：所有展示文本（标题/信息/命中检测输入）先 `html.unescape` 还原实体 → 正则剥除 `<[^>]+>` 标签 → 压缩空白 → 截断
3. **命中检测输入**：detect_hits 一律用清洗后文本，避免封面图 URL 里的词误命中
